# PAIMANA AI — dataset provenance and limitations

## Included project snapshots
This build replaces the 28-record demonstration dataset with the monthly project CSV snapshots supplied in the user's earlier PAIMANA-AI repository:

- January 2026: 1,702 records
- February 2026: 1,948 records
- March 2026: 1,941 records
- April 2026: 1,775 records
- May 2026: 1,987 records
- June 2026: 1,847 records
- July 2026: 1,775 records

The source archive also contained PAIMANA Flash Report PDFs for April, May, June and July 2026 and a July 2026 state-wise aggregate CSV. April, May and June PDFs are served from `public/reports/`. The supplied July PDF is structurally damaged and is not linked; the July report card links to the official PIB release instead. The original July state-wise CSV is retained in `data/source_reports/`; valid April–June PDFs are served from `public/reports/`.

## State-wise map data
The original `backend/data/statewise/July_2026_State-Wise.csv` was converted to `public/data/statewise/july-2026.json`. Its state rows provide project count, original outlay, revised outlay and cumulative expenditure. The sum of state-level counts is not presented as a unique all-India project total because the state summary can include multi-state coverage.

## Flash report archive
`data/flash_reports/flash_reports.json` contains report-card metadata for April–July 2026. April, May and June cards open the included PDFs. The supplied July PDF is damaged; its card links to the official PIB July 2026 release.

## Field mapping
The project CSVs were mapped into the new app's schema: project code/name, sector, line ministry, implementing agency, original/revised cost, expenditure, physical progress, sanction date, and original/revised commissioning dates.

## Important limitations (do not present inferred fields as official)
- The supplied project-level monthly CSVs do not contain project-level State/UT, bottleneck descriptions, or an explicit delay-months field. State is therefore marked as "Multi-State / Not specified in project-level source"; the app must not interpret that as a project location. The separate July state-wise CSV is used only for the map summary. It is not used to assign individual projects to states.
- `delay_months` is a derived proxy: months from the original commissioning date to the reporting month, only for records below 100% physical progress. It is not a reported official delay figure.
- The map displays state-wise project counts, original outlay, revised outlay and expenditure from the July state-wise source. The state-wise file does not provide risk or delay measures, so the map intentionally does not show state risk scores, delayed counts or project drill-downs.
- Risk scores and delay probabilities shown elsewhere are generated by this application's own analytics/risk logic. They are not official MoSPI/PAIMANA risk ratings or government predictions.
- Missing source values remain blank where possible; do not treat missing values as zero in external reporting.
- The old repository includes duplicate/alternate CSV exports. The clean monthly files were selected to avoid importing duplicate copies.

## Run
From this project folder:
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

Node.js 20+ is required.
